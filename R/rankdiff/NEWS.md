# rankdiff 0.1.0

## Initial release

- Added core package structure for fitting rank-diffusion style models in R.
- Added configuration helpers for defining input data, preprocessing options, and model settings.
- Added preprocessing, initialization, fitting, calibration, and diagnostics workflow.
- Added simulation-based evaluation utilities.
- Added ablation, sensitivity, and plotting utilities.
- Added save/load helpers for fitted results and analysis outputs.
- Added packaged toy data support via `inst/extdata`.
- Added test coverage for configuration, numerical helpers, save/load behavior, and end-to-end pipeline execution.
- Added package documentation and README.
